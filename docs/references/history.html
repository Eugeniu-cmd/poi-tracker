POI Tracker — History panel

v0.21 — 2026-10-21. Metallic gold replaces the amber (main-screen v0.34): the sub-header's chip, the dot of a waiting pass and the active POI row are gold (items 12, 40, 41). The shell of main-screen v0.33 brought a dark bar for a POI in progress to the column and the mini-map (items 2, 58) and smaller dialog buttons (item 63). The compass of main-screen v0.33 reaches the shell's styles, though no frame draws it (item 61). Frame I shows a refused removal and a refused type change (items 13, 47). The History panel covers the main area beside the live POI column, in POI or Route scope, and lists every pass this tablet recorded and every type change not yet in the sheet, newest first, with "Delete" on each pass, a deleted pass struck through while its removal waits, and a refused pass offering "Send again" and "Delete" (item 47). Every value inside the frames is a token of _tokens.css v0.16 (size C, screens.md item 67) and every rule follows screens.md v0.49. The shell (top bar, POI column, presets, drag corner, light and dark) is that of main-screen.html v0.34, copied unchanged: presets 800 × 1333 (the user's tablet in portrait, the default), 720 × 1000, 1333 × 800 and 1000 × 600; every frame also drags at its bottom-right corner. Nine states, A to I. The twelve proposals of v0.8 are approved (v0.12, screens.md v0.38).

Preset Theme Checking tool only — nothing here is part of the app.

I · A refused removal and a refused type change

Decision map
  • 13, 47 A removal the tracker's script refused: the pass stays struck through, "Not accepted" in the error colour, the reason, then "Send again" and "Cancel removal". "Cancel removal" asks nothing: the pass simply returns to "Sent", since nothing changes in the sheet.
  • 47 A refused removal does not count: the pass is still in the sheet, so POI 136 keeps its 41 passes and the chip "2,184 passes".
  • 12, 47 A type change is listed as "Type: Straight only", with the POI number in Route scope. It reads "Waiting" with the warning-colour dot while it waits, and leaves the list once it is in the sheet. Refused, it reads "Not accepted" with the reason, "Send again" and "Cancel change", which puts the old type back without a dialog. A waiting type change has no button: choosing the old type again on the type pill drops it. When putting the old type back has a consequence of item 64 for passes recorded since, the dialog of item 64 asks first.
  • 30, data-model While the change waits or is refused, POI 152 stays Straight only on this tablet, and "Load from sheet" leaves its type alone.
  • 47 The reason lines name the button of their own row: "or delete this pass" on a pass, "or cancel the removal" on a removal, "or cancel the change" on a type change.
  • 47, 72 The sync control reads "2 changes not accepted": one removal and one type change. Alone they read "1 removal not accepted" and "1 type change not accepted", as a pass reads "1 pass not accepted".
